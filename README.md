# NEXORA BANK

A premium, responsive digital banking prototype built for college and hackathon demonstrations.

## Demo safety

All balances, transactions, account details, login/OTP steps, transfers, card controls, and payments are simulated. Do not enter real banking credentials or financial information. This project does not connect to banks or payment systems.

## Run locally

Install dependencies with `pnpm install`, then run the web app with `pnpm --filter @workspace/nexora-bank run dev`.
